# Sprint_5

Финальный проект 5 спринта по UI-тестированию сервиса Stellar Burgers.

## Описание проекта
В проекте реализованы автотесты для проверки пользовательских сценариев сайта Stellar Burgers.

Автотесты покрывают:
- регистрацию нового пользователя;
- регистрацию с некорректным паролем;
- вход в аккаунт разными способами;
- переход в личный кабинет;
- переход из личного кабинета в конструктор;
- выход из аккаунта;
- переключение вкладок в разделе «Конструктор».

## Структура проекта
- `tests` - папка с тестами;
- `test_registration.py` - тесты регистрации;
- `test_login.py` - тесты входа;
- `test_personal_account.py` - тесты личного кабинета и выхода;
- `test_constructor.py` - тесты конструктора;
- `conftest.py` - фикстура драйвера;
- `locators.py` - локаторы элементов;
- `data.py` - тестовые данные;
- `generators.py` - генераторы данных.

## Что использовалось в проекте
- `Selenium` - для автоматизации действий в браузере;
- `Pytest` - для запуска тестов;
