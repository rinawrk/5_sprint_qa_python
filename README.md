# Sprint_5

Финальный проект 5 спринта по UI-тестированию сервиса Stellar Burgers.

## Описание проекта
В проекте реализованы автотесты для проверки пользовательских сценариев сайта Stellar Burgers.

Автотесты покрывают:
- успешную регистрацию нового пользователя;
- регистрацию с некорректным паролем;
- вход в аккаунт по кнопке «Войти в аккаунт» на главной странице;
- вход через кнопку «Личный кабинет»;
- вход через форму регистрации;
- вход через форму восстановления пароля;
- переход в личный кабинет;
- переход из личного кабинета в конструктор по кнопке «Конструктор»;
- переход из личного кабинета в конструктор по логотипу Stellar Burgers;
- выход из аккаунта;
- переключение между вкладками «Булки», «Соусы» и «Начинки» в разделе «Конструктор».

## Тестовые данные
Для тестов регистрации использовались сгенерированные данные:
- имя;
- email;
- валидный пароль;
- невалидный пароль.

Для тестов входа, переходов в личный кабинет и выхода использовались заранее зарегистрированные данные существующего пользователя.

## Структура проекта
- `tests` - папка с тестами;
- `test_registration.py` - тесты регистрации;
- `test_login.py` - тесты входа;
- `test_personal_account.py` - тесты личного кабинета, переходов и выхода;
- `test_constructor.py` - тесты конструктора;
- `conftest.py` - фикстура драйвера;
- `locators.py` - локаторы элементов страниц;
- `data.py` - URL страниц и данные существующего пользователя;
- `generators.py` - генерация тестовых данных для регистрации.

## Что использовалось в проекте
- `Selenium` - для автоматизации действий в браузере (Google Chrome);
- `Pytest` - для запуска тестов и работы с фикстурами.
